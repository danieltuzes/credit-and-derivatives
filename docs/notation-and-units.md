# Notation and units

This is the seed convention, not a complete glossary.

- Decimal rates are used in code: `0.05` means 5%.
- User interfaces label percentage inputs and convert at their boundary.
- Basis points must be named explicitly: 100 bps = 1 percentage point.
- Time is expressed in years only when a stated year-fraction convention makes
  that meaningful.
- Cash-flow signs must state whose perspective is used.
- Currency amounts must name their currency or be clearly labeled synthetic.
- Date-only financial schedules must not use local-time arithmetic.

Extend this document before introducing conflicting notation.
