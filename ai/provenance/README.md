# AI provenance records

Create one short Markdown or JSON record for material AI-assisted changes. It
should contain:

- date;
- model or tool name;
- prompt-template version;
- approved source IDs supplied;
- files or topics affected;
- outputs independently recalculated;
- human checks completed and still pending.

Do not store hidden reasoning, credentials, licensed source text, private data,
or unnecessary chat transcripts.
