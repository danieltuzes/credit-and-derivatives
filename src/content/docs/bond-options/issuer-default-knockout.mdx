## Contract definition

Here “knockout” has one precise trigger: if the issuer defaults before the
European exercise instant, the option is extinguished and pays no option
rebate. This is not a barrier tied to the bond's market price.

The underlying bond is a different claim. It may still pay recovery after
default. That recovery belongs in the bond tree, never in the option's default
branch.

## Value the underlying bond first

At an alive node [[lattice-time-index]] $i$,
[[lattice-state-index]] $j$, use the local node discount factor $d_{i,j}$, local
risk-neutral up weight $q_{i,j}$, [[conditional-node-survival-probability]]
$s_{i,j}$, next surviving cash flow $CF^B_{i+1}$, and local bond recovery
$R^B_{i,j}$. First collect the next-time value conditional on survival in the
local [[surviving-bond-continuation-value]]:

$$
\explain{surviving-bond-continuation-value}{H^B_{i,j}}
=\explain{surviving-bond-next-cash-flow}{CF^B_{i+1}}
+(1-\explain{knockout-node-up-weight}{q_{i,j}})
\explain{alive-bond-value}{B^{\mathrm{alive}}_{i+1,j}}
+\explain{knockout-node-up-weight}{q_{i,j}}
\explain{alive-bond-value}{B^{\mathrm{alive}}_{i+1,j+1}}.
$$

The [[alive-bond-value]] then separates survival and default:

$$
\explain{alive-bond-value}{B^{\mathrm{alive}}_{i,j}}
=\explain{knockout-node-discount-factor}{d_{i,j}}
\left[
\explain{conditional-node-survival-probability}{s_{i,j}}
\explain{surviving-bond-continuation-value}{H^B_{i,j}}
+(1-\explain{conditional-node-survival-probability}{s_{i,j}})
\explain{bond-default-recovery-cash}{R^B_{i,j}}
\right].
$$

Values are ex-cash-flow at each node. Recovery is approximated as paid at the
next lattice date, an explicit simplification.

## Apply the knockout to option continuation

At call expiry, conditional on the issuer still being alive,

$$
\explain{knockout-bond-option-value}{O^{\mathrm{KO}}_{T,j}}
=\max\left(
\explain{alive-bond-value}{B^{\mathrm{alive}}_{T,j}}
-\explain{option-strike-price}{K},0\right).
$$

Before expiry, the default branch is zero:

$$
\explain{knockout-bond-option-value}{O^{\mathrm{KO}}_{i,j}}
=\explain{knockout-node-discount-factor}{d_{i,j}}
\explain{conditional-node-survival-probability}{s_{i,j}}
\left[
(1-\explain{knockout-node-up-weight}{q_{i,j}})
\explain{knockout-bond-option-value}{O^{\mathrm{KO}}_{i+1,j}}
+\explain{knockout-node-up-weight}{q_{i,j}}
\explain{knockout-bond-option-value}{O^{\mathrm{KO}}_{i+1,j+1}}
\right].
$$

There is no recovery term in this option equation. If survival at the current
node is zero, the option value is zero even when the bond recovery is positive.

## Parity changes with the contingency

Vanilla put-call parity does not automatically survive this contract change.
Call minus put is zero in a pre-expiry default state, so its matching synthetic
forward must also be extinguished by the same default event. A default-free
forward is not the state-by-state match.

## Model and source boundary

Hull describes European bond options and separately describes credit
derivatives whose forwards/options cease to exist after reference-entity
default. The exact combination here—an issuer-default knockout option on the
issuer's bond—is a transparent teaching synthesis implementing the stated
contract, not a claim that all bond options use this convention. The joint
rate-credit lattice is supplied rather than calibrated.
