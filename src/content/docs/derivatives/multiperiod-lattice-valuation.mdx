## Repeat the one-period argument backward

The one-period binomial lesson valued two terminal payoffs. A multi-period
lattice applies the same pricing step at every node, beginning with the last
row and moving backward to \term\{valuation-time\}.

At node \term\{lattice-time-index\} $i$, \term\{lattice-state-index\} $j$, let local \term\{lattice-node-up-weight\} be $q_{i,j}$ and local
\term\{lattice-node-discount-factor\} be $d_{i,j}$. With local next-date cash
flow $\explain{lattice-next-cash-flow}{CF_{i+1,j}}$ paid just before the successor continuation value, the
\term\{lattice-node-value\} recursion is

$$
\explain{lattice-node-value}{V_{i,j}}
=\explain{lattice-node-discount-factor}{d_{i,j}}
\left[
(1-\explain{lattice-node-up-weight}{q_{i,j}})
\left(\explain{lattice-next-cash-flow}{CF_{i+1,j}}
+\explain{lattice-node-value}{V_{i+1,j}}\right)
+\explain{lattice-node-up-weight}{q_{i,j}}
\left(\explain{lattice-next-cash-flow}{CF_{i+1,j+1}}
+\explain{lattice-node-value}{V_{i+1,j+1}}\right)
\right].
$$

The implementation stores node $j$ and node $j+1$ as the two successors. The
labels “up” and “down” are conventions; the supplied probabilities and values
must use the same ordering.

## Timing is part of the model

This recursion treats the next-date cash flow as paid before the successor
continuation value is observed. A coupon-bond value at a node is therefore
ex-coupon after the cash flow at that node. Changing the exercise/coupon order
changes the contract and potentially its option payoff.
