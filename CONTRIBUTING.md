# Contributing

The root `README.md` is the editor handbook. Follow its workflow and run
`pnpm verify` before requesting review.

Keep pull requests focused. Explain the learner need, competencies affected,
source IDs, assumptions or convention changes, AI assistance, and verification
performed. New dependencies, schemas, lab types, progress behavior, or runtime
services require an architecture explanation.

Public contributions should not be accepted until the owner chooses code and
content licenses, supplies security contact details, adds real CODEOWNERS, and
enables branch protection.
